# 🐳 Docker Repository  

A collection of files and examples created while studying a [docker course](https://www.udemy.com/course/docker-basico-ao-avancado/).  
This repository serves as a sandbox for learning, experimenting, and consolidating Docker concepts.  

---

## 📘 About  

The repo includes:  
- Dockerfiles for building custom images  
- `docker-compose.yml` configurations for multi-container apps  
- Experiments with networking, volumes, and environment variables  
- Practical exercises covering common real-world use cases
